# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Contact the repository maintainer privately and include the affected version, reproduction steps and impact.

## Deployment guidance

- Publish only through HTTPS.
- Protect the repository with branch rules and required reviews.
- Keep GitHub Actions permissions read-only except for the Pages deployment job.
- Review embedded third-party libraries and licenses before release.
- Never commit PDF files containing confidential or personal information.
